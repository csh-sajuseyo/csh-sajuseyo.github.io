핵심 변경
- 검색·필터 하단시트가 손가락 움직임을 따라 실제로 위·아래 이동하고 전체/중간/접힘 3단계로 스냅
- 클러스터 학원 목록과 학원 상세정보도 같은 드래그 시트 사용
- 목록/상세를 중간 또는 접힘 상태로 내려 지도를 직접 보고 조작한 뒤 다시 위로 올릴 수 있음
- 상세 닫기(X)와 Android 뒤로가기는 기존처럼 상세 → 클러스터 목록 → 지도/검색 순서를 유지
- 지도 크기를 드래그 중 계속 재계산하지 않고 시트 transform만 움직여 확대·축소 성능 저하를 방지
- Android 앱과 iPhone Safari, PC 웹이 동일한 웹 상태 전환을 사용
