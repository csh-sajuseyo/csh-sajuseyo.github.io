카카오지도 연결 설정
사용할 키: 카카오디벨로퍼스 앱의 JavaScript 키
키는 이 브라우저의 localStorage에만 저장되며 출장계획 백업파일에는 포함되지 않습니다. REST API 키는 입력하지 않습니다.
현재 실행 주소:
카카오디벨로퍼스 → 앱 → 플랫폼 키 → 해당 JavaScript 키 → JavaScript SDK 도메인에 이 주소의 도메인을 등록해야 합니다.
